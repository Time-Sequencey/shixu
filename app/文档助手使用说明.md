# 文档助手使用说明

双击“启动文档助手.cmd”，使用窗口显示的本地地址。便携版包含 Windows x64 运行环境，无需安装 Node、Python 或 OCR 软件。使用更新的 Edge 或 Chrome，先完整解压，阅读期间保持启动窗口开启。不要直接打开 HTML。便携版遇到端口占用会自动换端口。

## 阅读与翻译

点击“选择文件”或拖入 PDF。左侧显示原始页面，右侧先显示重排预览，点击“翻译本页”或“一键翻译整份”后显示中文。扫描页先在本机分区 OCR，首次识别需要等待，状态栏会显示进度。整份翻译期间可继续翻页、输入页码和缩放；已完成页会保留，失败后可再次点击继续。

## 页面重建

按栏间空白、文字位置、缩进、行距、段落编号识别左右栏和自然段。左右栏分别翻译与排版，保留栏间空白、段首缩进和段间距。断行英文先合并为段落，再翻译，不把两栏拼成一行。

右页从空白页面重新组成：独立文字图层排版译文，图片在对应位置复制原图，不使用逐行白条遮盖原文。字号根据译文长度、栏宽与可用高度自动计算，空间充足时增大，过长时缩小。极密集页面仍可能需要放大阅读。

识别到的图片、图注、图内标签和独立公式整块保留，排除在翻译请求外。普通模式保留表格原图；电子专业版对能够识别出表头与网格的表格按单元格翻译。页边标志与图形也尽量保留。算法基于版面和图像特征，低清扫描、无边框图表、行内公式或特殊符号可能识别不完整，应对照左侧原文核对；不保证所有 PDF 的数学符号都能自动识别。

## 翻译服务与电子专业版

右上角可配置自己的 DeepSeek API Key，翻译优先使用 DeepSeek；文字会发送至该服务并可能产生费用。密钥仅保存于本机服务内存，关闭服务后清除，不写入导出 PDF 或文件。弹窗可查询账户余额和本次服务累计 token 用量，token 数不等同于金额。DeepSeek 出错不会自动转发到公共服务。

未配置 Key 时使用 Google 翻译或 MyMemory 备用服务，可能限流或无可用额度。阅读、分块和 OCR 可离线；翻译及余额查询需要网络。电子专业版固定常见电子器件、电气参数译法，VIN、DIM、CSN、SW、GND 等代号尽量保持原样；专业结论仍以原文为准。

在左右页面的可选文字中选中一段英文，可临时显示中文，鼠标移开恢复；图片内文字和保留的公式不是可选文字。

## 导出和缓存

整份翻译完成后可导出“中文 PDF”或“中英对照 PDF”。中文版每页与原页尺寸相同；对照版每张纸左右并排放置原页与译页。导出与阅读使用同一排版引擎，文件保存至浏览器下载目录。当前导出是图像 PDF，不包含可搜索或可复制的译文层。

译文按文档内容、翻译模式和排版版本缓存在当前浏览器本地存储。切换专业模式会读取该模式的缓存，不混用两种译文。新版分块与旧版不同，旧缓存不复用，需要重新翻译。换浏览器、换本地端口或清除站点数据也可能使缓存不可用。

更新后关闭旧启动窗口，重新双击启动器，再在浏览器按 Ctrl+F5 刷新。仅关闭浏览器不会关闭旧服务。便携版出错可运行“检查运行环境.cmd”；自检不调用收费翻译接口。包内不包含私人论文、API Key、账户余额或个人浏览器缓存。

## 图表边界修复（rebuild-3）

单栏图表的轴标签与图注不再跨栏收集；保留的图表与公式分别裁剪，不再合并成吞入旁边正文的大矩形。多子图按连续区域保留，同时保留坐标轴单位和子图编号。正文遇到图像或公式时分开排版，避免跨越受保护区域。新的分块版本不会复用旧的错误译文缓存，更新后需重新翻译。

## 电子专业版表格翻译（rebuild-4-tables）

勾选右上角“电子专业版”后，立即翻译当前页；后续可点“翻译本页”或“一键翻译整份”。识别引脚表、电气参数表、额定值与工作条件表的行列和合并单元格，翻译表头、参数名称、测试条件及引脚功能说明。表格按原位置重新排版并自动适配字号，数值、单位、符号列、引脚代号和公式保留原文，图片继续保留原图。

中文 PDF 与中英对照 PDF 包含同样的表格译文。普通版与专业版缓存独立，关闭专业版后恢复表格原图。为避免图形被误判成表格，只有识别到可靠表头和网格时才启用单元格翻译；复杂无边框表格、低清扫描和旋转表格仍可能保留原图。OCR 识别的字符错误不能仅靠翻译修正，请对照原文核对关键电气参数。
